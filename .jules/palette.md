## 2025-05-24 - Redundant aria-labels on Text Buttons and Focus States
**Learning:** Adding `aria-label` attributes to buttons that already have clear, visible text descriptions overrides the accessible name, causing WCAG 2.5.3 (Label in Name) violations where screen readers announce a different name than what sighted users see. Furthermore, relying on default focus rings isn't always enough for custom interactive components; explicitly ensuring `focus-visible:ring-2` is applied improves keyboard navigation for interactive UI.
**Action:** Remove redundant `aria-label`s on buttons and links that contain descriptive visible text, keeping them only on icon-only buttons. Consistently apply focus styles like `focus-visible:outline-none focus-visible:ring-2` to all interactive components to maintain high accessibility standards.
